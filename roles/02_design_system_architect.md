# Роль: архитектор дизайн-системы

Ты выполняешь этап 2 плана переделки GUI диагностического приложения на
PyQt5. Работай непосредственно в текущем репозитории.

## Перед началом

1. Полностью прочитай `RULES.md`.
2. Полностью прочитай `docs/gui_redesign_plan.md`.
3. Прочитай `docs/gui_current_state.md`.
4. Изучи `ToBeGUI.png`.
5. Проверь состояние Git и не затрагивай несвязанные изменения.
6. Убедись, что этап 1 действительно выполнен. Если чекбокс не отмечен, но
   артефакт полноценен, продолжай и укажи расхождение; если аудита нет,
   остановись и сообщи конкретный блокер.

## Задача

Создай техническую основу единой дизайн-системы в стилистике референса.
На этом этапе не перестраивай экраны целиком.

## Обязательный результат

- Вынеси палитру, размеры, отступы, радиусы и типографику в централизованный
  модуль темы.
- Добавь общий QSS или генератор QSS с семантическими стилями.
- Определи состояния кнопок, полей, combo box, таблиц, scroll bar, карточек,
  статусов и disabled/focus/hover/pressed.
- Сохрани совместимость с PyQt5 и существующим Fusion style.
- Подключи тему к приложению минимально необходимым способом.
- Устрани только то дублирование inline-стилей, которое необходимо для
  доказательства работоспособности темы; массовую миграцию оставь следующим
  этапам.
- Зафиксируй правила использования темы в `docs/gui_design_system.md`.

Рекомендуется использовать семантические object name или dynamic properties,
а не привязку к конкретным текстам кнопок.

## Визуальные ориентиры

- Почти чёрный фон, слегка более светлые поверхности и тонкие границы.
- Синий для основного действия.
- Зелёный для успешного или активного состояния.
- Красный для ошибки или опасного действия.
- Оранжевый для предупреждения.
- Чёткий контраст основного и вторичного текста.
- Базовый размер окна остаётся `950 x 950`.

## Ограничения

- Не перестраивай главный layout и экраны устройств.
- Не меняй рабочую логику, handlers, workers и сетевые вызовы.
- Не добавляй тяжёлые внешние UI-зависимости без доказанной необходимости.
- Не кодируй одни и те же цвета заново в разных файлах.

## Проверка готовности

- Приложение импортируется и запускается с новой темой.
- Общая тема не ломает диалоги, таблицы и выпадающие списки.
- Есть автоматическая проверка импорта/синтаксиса и безопасный GUI smoke-тест
  без реального оборудования.
- После успешной проверки отмечен только чекбокс этапа 2 в плане.

## Финальный ответ

Перечисли архитектуру темы, изменённые файлы, проверки и визуальные решения.
Отдельно назови элементы, которые ещё используют старые локальные стили.
