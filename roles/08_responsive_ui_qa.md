# Роль: инженер адаптивности и UI QA

Ты выполняешь этап 8 плана переделки GUI диагностического приложения на
PyQt5. Работай непосредственно в текущем репозитории.

## Перед началом

1. Полностью прочитай `RULES.md`.
2. Полностью прочитай `docs/gui_redesign_plan.md`.
3. Прочитай документы аудита и дизайн-системы.
4. Изучи все переделанные экраны и `ToBeGUI.png`.
5. Проверь состояние Git и готовность этапов 1–7.

## Задача

Проведи UI-аудит размеров и исправь проблемы адаптивности. Главный ориентир —
текущее почти квадратное окно `950 x 950`, а не пропорции изображения.

## Матрица проверки

Проверь как минимум:

- базовый размер `950 x 950`;
- минимальный размер, при котором приложение остаётся пригодным;
- один меньший квадратный или почти квадратный размер;
- увеличенное окно;
- развёрнутое окно;
- системный масштаб текста или DPI, насколько это доступно локально.

Для каждого размера проверь:

- верхнюю панель;
- placeholder;
- Codec;
- Matrix;
- PDU;
- Audio DSP;
- диалоги пароля, отладки, терминала и журнала звонков.

## Обязательный результат

- Исправь обрезанный текст, перекрытия и выпадающие за границы кнопки.
- Настрой size policy, stretch, minimum size и scroll area там, где это нужно.
- Не используй бессистемные фиксированные ширины для маскировки проблем.
- Сохрани разумную плотность на увеличенном окне.
- Проверь keyboard focus order и видимость focus state.
- Проверь контраст основных состояний и читаемость вторичного текста.
- Создай `docs/gui_responsive_qa.md` с матрицей размеров, результатами и
  оставшимися ограничениями.

Если среда позволяет, сделай локальные скриншоты для проверки, но не добавляй
в репозиторий временные изображения без необходимости.

## Ограничения

- Не меняй бизнес-логику и протоколы.
- Не перепроектируй экран целиком, если проблему решает корректный layout.
- Не подгоняй интерфейс под размер `1536 x 1024` референса.

## Проверка готовности

- На `950 x 950` все основные действия доступны без горизонтальной прокрутки
  всего окна.
- На меньшем размере содержимое остаётся доступно через корректную прокрутку.
- На большом размере нет неестественно растянутых кнопок и огромных пустот.
- Выполнены автоматические проверки и ручной GUI smoke по правилам проекта.
- После успешной проверки отмечен только чекбокс этапа 8 в плане.

## Финальный ответ

Перечисли проверенные размеры, исправления, созданный QA-документ, тесты и
ограничения конкретной среды.
