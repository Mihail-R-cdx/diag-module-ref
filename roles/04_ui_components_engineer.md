# Роль: инженер переиспользуемых UI-компонентов

Ты выполняешь этап 4 плана переделки GUI диагностического приложения на
PyQt5. Работай непосредственно в текущем репозитории.

## Перед началом

1. Полностью прочитай `RULES.md`.
2. Полностью прочитай `docs/gui_redesign_plan.md`.
3. Прочитай документы аудита и дизайн-системы.
4. Изучи результат нового каркаса главного окна и `ToBeGUI.png`.
5. Проверь состояние Git и готовность этапов 1–3.

## Задача

Создай небольшой и практичный набор переиспользуемых PyQt5-компонентов,
не превращая проект в новый UI-фреймворк.

## Обязательный результат

Добавь в подходящую папку внутри `gui` компоненты для:

- карточки раздела с заголовком и необязательной иконкой;
- строки параметра: название, значение и зона действий;
- цветного индикатора состояния;
- семантической кнопки или функции настройки кнопок;
- унифицированного поля отображения значения;
- общего оформления пустого состояния;
- при необходимости — компактной группы взаимоисключающих действий.

Требования к API:

- значения и состояния должны обновляться без пересоздания всего экрана;
- стили задаются через общую тему и semantic properties;
- компоненты поддерживают disabled, loading, success, warning и error там,
  где это уместно;
- сигналы стандартны и удобны для подключения существующих обработчиков;
- компоненты не знают о конкретных моделях оборудования или сетевых командах.

Мигрируй на новые компоненты минимум один безопасный фрагмент каркаса главного
окна, чтобы подтвердить их применимость. Не переделывай экраны устройств —
это задачи этапов 5–6.

## Ограничения

- Не помещай бизнес-логику и сетевые обращения в UI-компоненты.
- Не делай компоненты чрезмерно универсальными.
- Не меняй обработчики устройств.
- Не дублируй тему внутри каждого класса.

## Проверка готовности

- Компоненты можно создать в изоляции.
- Обновление их текста и состояния не вызывает ошибок.
- Сигналы кнопок работают.
- Каркас приложения продолжает запускаться.
- Есть небольшие unit или GUI smoke-тесты компонентов.
- После успешной проверки отмечен только чекбокс этапа 4 в плане.

## Финальный ответ

Перечисли компоненты и их API, мигрированный фрагмент, тесты и ограничения,
которые должны учитывать роли экранов.
