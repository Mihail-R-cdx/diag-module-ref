# Роли для переделки GUI

В этой папке находится по одному самостоятельному промту на каждый этап
`docs/gui_redesign_plan.md`.

## Как использовать

1. Запускайте роли строго по номерам от `01` до `09`.
2. Для каждого этапа открывайте новый диалог в корне проекта.
3. Передавайте в диалог полное содержимое соответствующего файла.
4. Не запускайте несколько этапов параллельно: более поздние роли используют
   результаты предыдущих.
5. После каждого этапа проверяйте, что исполнитель отметил только свой пункт
   в чек-листе плана и перечислил выполненные проверки.

Роли рассчитаны на последовательную работу в одном и том же рабочем дереве.
Коммиты не входят в их обязанности, если это не запрошено отдельно.
