# Роль: инженер экрана кодека

Ты выполняешь этап 5 плана переделки GUI диагностического приложения на
PyQt5. Работай непосредственно в текущем репозитории.

## Перед началом

1. Полностью прочитай `RULES.md`.
2. Полностью прочитай `docs/gui_redesign_plan.md`.
3. Прочитай документы аудита и дизайн-системы.
4. Изучи API компонентов этапа 4 и текущее содержимое
   `gui/screens/codec_screen.py`.
5. Изучи `ToBeGUI.png`.
6. Проверь состояние Git и готовность этапов 1–4.

## Задача

Полностью перестрой визуальную часть экрана кодеков, сохранив существующее
поведение Huawei TE20, Huawei TE40, CloudLink Bar 310 и Polycom RPG 310.

## Обязательный результат

- Создай карточку основной информации о кодеке.
- На доступной ширине используй две логические колонки; на узкой ширине
  обеспечь читаемую адаптацию.
- Отобрази только реально поддерживаемые данные: прошивку, модель, серийный
  номер, MAC, uptime, SIP и другие текущие поля.
- SIP-статус оформи индикатором и текстом; сохрани действие исправления SIP.
- Создай карточку параметров с отдельными строками управления.
- Используй новые общие компоненты и тему.
- Сохрани управление громкостью, mute, презентацией, sleep/wake TE20,
  monitor audio и журналом звонков.
- Сохрани таймеры, задержанные refresh и повторное использование session
  handler.
- Не привязывай логику к видимому тексту кнопок, если можно использовать
  свойства или явное состояние.
- Убери устаревшие локальные стили только в пределах экрана кодека.

## Совместимость

Сохрани публичные методы обновления данных и все обработчики, используемые
главным окном. Если внутренние виджеты заменяются, сохрани ожидаемые словари
и ссылки либо аккуратно обнови все места использования и тесты.

## Ограничения

- Не меняй протоколы оборудования, handlers и workers.
- Не упрощай функциональность ради соответствия картинке.
- Не показывай фиктивные данные.
- Не переделывай Matrix, PDU и Audio DSP.

## Проверка готовности

- Все модели кодеков корректно строят экран.
- Обновление данных меняет существующие виджеты без утечек и дублей.
- Кнопки управления подключены к прежним обработчикам.
- Проверены loading/error/unavailable и специальные состояния TE20.
- Экран проверен на базовом размере окна `950 x 950`.
- Выполнены релевантные unit и GUI smoke-тесты без реального оборудования.
- После успешной проверки отмечен только чекбокс этапа 5 в плане.

## Финальный ответ

Перечисли сохранённые функции, изменённые файлы, тесты и сценарии, которые
потребуют проверки на реальном оборудовании.
