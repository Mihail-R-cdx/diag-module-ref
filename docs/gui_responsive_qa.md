## Исправления

- Установлен поддерживаемый минимум окна `800 × 700`.
- Компактный size hint списка устройств больше не расширяет минимальную ширину
  окна по самому длинному названию.
- Верхняя панель уплотнена без фиксированной подгонки под один экран.
- Matrix и PDU получили вертикальные scroll area с отключённой горизонтальной
  прокруткой.
- Поля значений ограничены разумной максимальной шириной `360 px`.
- Исправлена вложенность строк Codec: пустой `QLayout` больше не принимается за
  отсутствие целевого layout.
- При перестроении Codec старые карточки сразу скрываются до deferred delete,
  поэтому не перекрывают новые.
- Фон scroll-content и строк параметров приведён к тёмной поверхности темы.
- Нижний idle-статус сокращён, чтобы время обновления не обрезалось на
  минимальной ширине.
- Явно задан порядок фокуса:
  устройство → IP → пароль → обновление → отладка.
- Контраст `text_secondary` проверен относительно фона приложения и карточек:
  отношение не ниже `4.5:1`.
- Диалог терминала уменьшен до ширины, доступной при минимальном размере окна.
