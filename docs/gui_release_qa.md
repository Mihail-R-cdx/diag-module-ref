## Известные ограничения и блокеры

### Блокер релиза

Требование об отсутствии GUI-операций, блокирующих event loop, не выполнено.
Несколько пользовательских действий синхронно выполняют подключение или
сетевой запрос в GUI thread:

- журнал звонков: `gui/screens/codec_screen.py:421`;
- создание/подключение codec handler: `gui/screens/codec_screen.py:1274`;
- подключение и переключение Matrix:
  `gui/screens/matrix_screen.py:254`, `gui/screens/matrix_screen.py:307`,
  `gui/main_window.py:721`;
- управление PDU: `gui/screens/pdu_screen.py:261`,
  `gui/main_window.py:1370`.

Медленное или недоступное устройство способно заморозить окно. Безопасное
исправление требует переноса операций в workers, привязки результата к
request identity и корректного cleanup; это не локальная финальная правка.

### Прочие ограничения

- Реальная совместимость команд, таймаутов и ответов оборудования не
  проверена без явного разрешения на подключение.
- Проверен системный масштаб 125%; другие DPI покрыты только layout-тестами.
- `CallLogWindow.load_from_device()` остаётся placeholder, но рабочий путь
  журнала идёт через `CodecScreen.open_call_log_window()`.
- В checklist плана этапы 2, 3, 5 и 6 формально не отмечены, хотя
  соответствующие реализации присутствуют в истории Git. Этап 9 оставлен
  неотмеченным из-за блокера event loop.

## Итоговое решение

**Не готово.** Функциональный hardware-free и визуальный smoke успешны,
но синхронные сетевые операции в GUI thread являются критическим
нерешённым блокером обязательной приёмки. Этап 9 в плане не отмечен.

## Дополнительная hardware-проверка

Результат от 30 июня 2026 года зафиксирован в
`docs/gui_real_hardware_qa.md`. Аутентифицированный read-only smoke успешен на
Bar 310, TE-20, TE-40 и IN1804; журналы звонков проверены без сохранения
персональных данных, TE20 polling и Extron keepalive/cleanup успешны.

Исправлены утечки credentials в debug/terminal logs и disabled refresh после
смены устройства во время запроса. Реальное оборудование подтвердило блокер:
Call Log, создание persistent Extron session и Matrix keepalive выполняют
синхронные сетевые операции в GUI thread. Максимальный измеренный stall —
`4.141 s`. Вердикт релиза остаётся **«не готово»**.

После отдельного подтверждения выполнен GUI volume cycle с обязательным
rollback: Bar310 `13 → 14 → 13`, TE20 `15 → 16 → 15`, TE40
`13 → 14 → 13`. Все исходные значения повторно прочитаны и подтверждены.
Volume flow также синхронен; на TE40 измерен stall `1.031 s`.

После отдельного разрешения TE20 с реальным `sleep=On` пробуждён GUI-кнопкой;
повторное чтение подтвердило `sleep=Off`. Устройство намеренно оставлено
пробуждённым, обратная sleep-команда не выполнялась.

Расширенный state-changing smoke с rollback:

- speaker mute TE20 `15 → 0 → 15` и TE40 `13 → 0 → 13` — успешно;
- presentation TE20 `Stopped → Started → Stopped` — успешно;
- presentation Bar310 без источника — ожидаемая ошибка, итоговый `Stop`;
- presentation Bar310 с видео:
  `Start → Stop → Start → Stop` — успешно;
- presentation TE40 после подключения входного сигнала:
  `Stop → Start → Stop` — успешно;
- IN1804 routing `2 → 1 → 2` — успешно.

Все финальные состояния повторно прочитаны: Bar310 `Stop/Off/13`, TE20
`Stopped/Off/15`, TE40 `Stop/Off/13`, IN1804 — вход `2`. Максимальный
измеренный stall теперь `5.032 s` на presentation/wake flow Bar310. Вердикт
релиза остаётся **«не готово»**.

Контролируемый повтор TE40 без входного сигнала вернул
`success=0`, `error.id=100666963`, `error.code=100687877`, оставив состояние
`Stop`. GUI теперь отображает понятное сообщение об отсутствии видеосигнала;
regression-набор после исправления — `39` тестов, `OK`.

Bar310 без источника после разрешённого wake вернул
`success=0`, `error.id=100666941`, `error.code=100687877`; presentation
осталась `Stop`, финальный Stop подтверждён. GUI показывает понятное сообщение
об отсутствии видеосигнала с диагностическими кодами.

После подключения видео Bar310 автоматически перешёл в `Start`; полный GUI
cycle `Start → Stop → Start → Stop` успешен. Финальное состояние:
presentation `Stop`, sleep `Off`, speaker volume `13`.
